2. 언제 여는가? (요일별 영업시간, 휴무일)
3. 무엇을 얼마에 살 수 있는가?

## 조사 방법
- 도구: ego-browser
- 가게 목록: 카카오맵에서 "광주 동명동 맛집"을 검색해 나온 첫 페이지 15곳 (https://map.kakao.com/?q=광주%20동명동%20맛집, 확인 2026-11-12)
- 가게별 정보: 각 가게의 카카오맵 상세 페이지 (아래 표의 출처 칸)
- 동명동 소재 확인: 상세 페이지의 지번 주소가 15곳 모두 "동명동"으로 시작함

## 기록 형식
- 영업시간: `월–금 11:00–21:00` 처럼 요일별, 24시간제. 브레이크타임(BT)과 라스트오더(LO)는 괄호에 적는다
- 휴무일: `월` / `없음` / `미확인`

- 확인 날짜: `YYYY-MM-DD`
- 확인되지 않은 칸은 비워 두지 않고 "미확인"으로 적는다

### 값을 고른 기준
1. **두 출처가 같으면** 그 값을 적는다 (표시 없음)
2. **한쪽에만 있으면** 그 값을 적고 어느 출처의 값인지 표시한다: ⓚ = 카카오맵 값, ⓝ = 네이버지도 값
3. **두 출처가 다르면** 날짜로 더 최신임이 확인되는 쪽을 적고 같은 방식(ⓚ/ⓝ)으로 표시한다
   - 메뉴 가격: 네이버 메뉴 페이지에 "최근 업데이트" 날짜가 있는 경우 네이버 값을 썼다 (돌애 26.09.01, 한식경 26.10.13, 물고기 커피로스터스 26.10.29, 코너베이크샵 26.02.14). 카카오맵에는 메뉴 날짜가 없다
   - 900달러 영업시간: 네이버 소식란의 2026-10-30 "금, 토, 일 연장영업 시작" 공지를 근거로 네이버 값을 썼다
4. **두 출처가 다른데 어느 쪽이 최신인지 날짜로 확인할 수 없으면** "미확인"으로 적고 두 값을 괄호에 모두 남긴다 (영업시간, 휴무일, 연락처 대부분, 날짜 없는 메뉴 가격)

### 표 읽는 법
- 휴무일 "매주 ○": 카카오맵에서 해당 요일이 휴무로 나오고, 네이버지도에 "정기휴무 (매주 ○요일)"로 표시된 경우
- 휴무일 "미확인": 두 출처 모두 일주일 내내 영업으로 표시하지만 휴무가 없다는 안내도 없는 경우, 또는 두 출처가 다른 경우
- 업종: 카카오맵 기준. 코다만 메뉴(커피·디저트)와 네이버 업종을 근거로 "카페·디저트"로 고쳤다
- 대표 메뉴: 1차 수집 때 고른 메뉴를 유지했다. 두 메뉴 중 날짜가 확인된 값이 있는 메뉴를 앞에 적었다
- 대표 메뉴 중 ⓚ 표시가 있는 품목(아이스크림라테, 아메리카노·라떼(아우스밀), 바나나 케이크, 우렁이쌈밥정식, 해수 물회, 굴전, 커스텀 크레페)은 네이버 메뉴 목록에 없었다. 판매가 중단됐을 수도 있지만 확인하지 않았다
- 그랩앤고: 두 번째 메뉴는 1차 수집 때부터 "미확인"
