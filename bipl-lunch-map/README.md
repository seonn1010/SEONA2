# 비플식권 점심지도

L.L.M Academy(광주 서구 상무중앙로 44) 반경 600m 안에서 **비플페이 식권을 쓸 수 있는 가게**를 지도와 목록으로 보여주는 한 페이지짜리 웹사이트.

## 기능
- 지도: 아카데미 위치, 반경 600m 원, 가게 위치(카테고리별 색)
- 탭: 전체 / 음식점 / 카페 / 편의점·마트
- 가게 카드: 직선거리, 예상 도보 시간(분속 67m), 대표메뉴 2~3개와 출처
- 메뉴·가게 이름 검색, 대표메뉴 칩을 누르면 같은 메뉴를 파는 곳만 보기
- 네이버지도 / 카카오맵 바로가기 버튼

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 동작 (Leaflet 1.9.4 + OpenStreetMap 지도) |
| `data.js` | 가게 데이터 60곳 (이름, 주소, 좌표, 거리, 대표메뉴, 출처) |
| `tools/` | 데이터를 만든 스크립트와 중간 결과 (좌표 캐시, 거리 계산) |
| `HANDOFF.md` | 다음 작업자를 위한 인수인계 메모 (결정 사항, 남은 일) |

`index.html`을 브라우저로 열면 바로 볼 수 있다. 빌드 과정은 없다.

## 데이터를 만든 방법 (2026-11-17)
1. **가게 목록**: 비플페이 앱의 '전체 가맹점 사용처'와 '비플식권 사용처' 화면(광주 서구)을 캡처해 옮겨 적음
2. **좌표**: 도로명주소를 OpenStreetMap Nominatim으로 좌표 변환함. 건물번호가 등록되지 않은 주소는 같은 도로의 다른 건물번호로 보정하거나 도로 위치로 추정함(사이트에 '위치 근사'로 표시, 약 ±150m)
3. **600m 필터**: 아카데미 좌표에서 직선거리 600m 이내만 남김 (처음엔 1km였으나 너무 멀어서 줄임)
4. **제외**: 술집 7곳(점심 용도와 맞지 않음), 이마트 상무점(지번 주소만 있어 위치 미확인)
5. **대표메뉴**: 웹 검색으로 조사하고 가게마다 출처 링크와 확인일을 붙임. 프랜차이즈는 브랜드나 다른 지점 기준이라 표시함. 찾지 못한 곳은 '미확인'으로 둠
   - 2026-11-18: 남은 23곳을 에고브라우저로 카카오맵·네이버 지도 매장 페이지에서 직접 확인해 19곳 추가(가격 포함). 음식점·카페 46곳 중 **42곳 확인, 4곳 미확인**
