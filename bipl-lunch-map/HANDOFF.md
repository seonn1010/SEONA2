# 인수인계 메모: 비플식권 점심지도

새 세션은 이 파일부터 읽는다. 마지막 정리: 2026-11-18. 작업 브랜치는 `claude/serene-gates-e2pyvm`이다.

## 지금 상태
- 반경 **600m**(직선거리), 가게 **60곳**: 음식점 33, 카페 13, 편의점·마트 14
- 대표메뉴는 음식점·카페 46곳 중 **42곳 확인**, 4곳은 "대표메뉴 미확인" (2026-11-18 로컬 세션에서 19곳 추가)
- 지도는 Leaflet 1.9.4와 OpenStreetMap 기본 타일을 쓴다. 북쪽이 위다.
- 미리보기(Artifact, 비공개): https://claude.ai/artifact/EMtVQks6yqPmZuMgAkJgyG
  - 미리보기는 외부 이미지가 막혀서 OSM 타일을 페이지 안에 base64로 넣었다(`tools/embed.py`).

     - **빽바지집**(치평로 79): 인허가상 한식 일반음식점. 카카오맵엔 치평로 77의 "빽바지포차"(16:30 영업 시작)만 있다. 같은 가게인지 미확인
     - **뉴벨퀴진**(마륵복개로 104): 인허가 이름은 "누벨퀴진". 지도 앱에 메뉴 정보 없음
   - 업종 불일치: **모람**(네이버 '테이크아웃커피'), **티파라치**(카카오 '커피전문점')는 데이터에 '음식점'으로 들어가 있다. 카페로 옮길지 사용자에게 물어볼 것
   - 점심 영업 미확인: 쪽갈비대장(카카오 17:00~04:00), 돈 고기집(네이버 17:00 시작)
   - `index.html` 128줄 안내문이 "대표메뉴는 웹 검색으로 조사"라고 되어 있다. 지도 앱 확인분이 생겼으니 문구 수정이 필요하다(클라우드 세션 담당 파일이라 손대지 않음).

## 이미 해봤는데 안 된 것
- **CARTO 지도(Positron/Voyager)**: 2026년 기준 무료 API 키가 필요하다. 키 없이 받으면 타일에 "API KEY REQUIRED"만 찍힌다.
- **OSM 타일에 색 필터(회색/저채도)**: 사용자가 "별로"라고 함
- **직접 그린 SVG 일러스트 지도**(28° 회전): 사용자가 원하지 않음
- **Remote Control로 사용자 컴퓨터 연결**: 이 클라우드 세션에서 연결 가능한 폴더가 0개로 나와 실패

## 데이터 다시 만드는 법 (`tools/`)
| 파일 | 역할 |
|---|---|
| `candidates.py` | 앱 캡처에서 옮겨 적은 후보 가게 목록 (휴대폰 기준 3.0~5.3km 구간만) |
| `geocode.py` | 주소를 Nominatim 좌표로 변환해 `geo_cache.json`에 저장 (1초에 1건, 빠르면 429 오류) |
| `refine.py` | 건물번호가 없는 주소를 이웃 번호로 보정 |
| `geo_cache.json` | 주소별 좌표와 정확도 (`exact`, `approx`) |
| `finalize.py` | 같은 도로의 정확한 번호끼리 보간하고, 아카데미 기준 거리를 계산해 `all_rows.json` 생성 |
| `all_rows.json` | 후보 전체와 거리, 정확도(정확/보정/근사/미확인) |
| `build_data.py` | 반경·술집 제외·대표메뉴(`M` 딕셔너리)를 적용해 `../data.js` 생성 |
| `make_artifact.py`, `embed.py`, `tiles.py` | 미리보기용 단일 HTML 만들기 (Leaflet은 `npm install leaflet@1.9.4`, 타일은 `tiles.py`로 다시 받기) |

- 반경을 바꾸려면 `build_data.py`의 `> 600`과 `"radius": 600`을 고치고 `cd tools && python3 build_data.py`를 실행한다. 그 뒤 `index.html`, `README.md`의 "반경 600m", 술집 개수 문구도 같이 고친다.
- 대표메뉴를 바꾸려면 `build_data.py`의 `M`을 고쳐도 되고 `data.js`를 직접 고쳐도 된다. 단, `build_data.py`를 다시 돌리면 `data.js`를 손으로 고친 내용은 덮어써진다. 한 가지 방법으로 통일할 것.

## 데이터 주의점
- "위치 근사"(지도에 건물번호가 없어 도로 위치로 추정, 약 ±150m): 마륵복개로·마륵로·상무공원로 10·운천로 206 등
- 이마트 상무점은 지번(치평동 1208-5)만 있어서 위치 미확인이라 제외했다.
- 골든웨이브(운천로 261)는 같은 주소의 "소이연남 광주상무점" 메뉴를 넣었다. 같은 가게인지는 미확인.
- 대표메뉴 출처 링크는 웹 검색 결과에 나온 링크다. 원문 페이지는 직접 열어보지 못했다(클라우드 네트워크 제한).
